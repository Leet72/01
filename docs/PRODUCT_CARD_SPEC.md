# Карточка товара и сравнение

## Цель
Карточка — инженерный паспорт, а не прямой вывод всех полей базы.

## Шапка
Показывать: производитель, модель, тип, грузоподъёмность, скорость, мощность, подвес, MR/MRL и выбранное исполнение.

## Блоки характеристик
- Основное
- Привод
- КВШ и канаты
- Эксплуатация
- Тормоз
- Габариты и присоединение

Единый формат: `Наименование параметра, размерность`.

## GTW9S — подтверждённые замечания
- скорость `1,0 м/с`, а не `1 м/с`;
- подвес 1:1 должен быть виден;
- для безредукторных не выводить вводящий в заблуждение параметр «Количество скоростей»;
- «Обороты» → «Номинальная частота вращения, об/мин»;
- «Частота» → «Номинальная частота, Гц»;
- «Канаты» → «Число канатов, шт. × Диаметр канатов, мм»;
- «Шаг канавок» → «Расстояние между канатами, мм»;
- режим работы S5 (40%);
- 180 включений/час по умолчанию для указанного исполнения;
- «Тормоз» → «Напряжение тормоза, В»;
- отдельный номинальный ток тормоза 2×1,28 А для указанного исполнения;
- отсутствующие габариты не выдумывать — использовать исходный чертёж.

## Сравнение
- 2–4 исполнения;
- режим по умолчанию: `Только отличия`;
- дополнительный режим: `Все параметры`;
- одинаковые параметры скрыты/приглушены;
- отличия визуально выделены;
- сверху краткое резюме «Главные отличия»;
- сравниваются конкретные исполнения, а не абстрактные модели.
