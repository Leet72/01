# Реестр источников Liftorg

## Приоритет источников
1. Последнее подтверждённое замечание заказчика/инженера.
2. Русский переведённый документ — для пользовательских подписей.
3. TDNA Traction Survey — для инженерного смысла и схем.
4. Основной Excel-каталог — технические данные исполнений.
5. `Калькулятор-2.xlsx` — эталон старого коммерческого калькулятора.
6. Документ нового CPQ/RFQ — требования следующего этапа.
