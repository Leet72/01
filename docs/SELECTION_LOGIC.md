# Логика инженерного подбора

## Статусы
- PASS — известные данные исполнения соответствуют выбранным условиям.
- UNKNOWN — конфликта нет, но часть исходных данных отсутствует; требуется уточнение.
- FAIL — есть явное противоречие выбранным параметрам.

## Основные правила
- производитель — точное совпадение;
- тип лебёдки — точное совпадение;
- грузоподъёмность — точное совпадение;
- скорость — диапазоны с включительными границами;
- подвес — точное совпадение;
- безредукторная машина — односкоростная;
- мощность — диапазоны с включительными границами;
- консольная нагрузка: допустимый максимум изделия ≥ требуемой;
- высота подъёма: допустимый максимум ≥ требуемой, только если значение известно;
- диаметр КВШ, число/диаметр канатов, включения/час — точные параметры;
- тормоз — нормализованное напряжение;
- размещение — MR/MRL.

## WJC-T
По уточнению заказчика WJC-T = `Безредукторная объёмная таблетка`, размещение = `Без машинного помещения (MRL)`.

Результат каталога группируется по модели. Для расчёта/опросника/заказа всегда должен быть выбран конкретный execution/product_id.
