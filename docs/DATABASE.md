# База данных каталога

## Что представляет собой база
Excel был исходником. Рабочая база — структурированная SQLite-БД, где одна запись `products` соответствует одному конкретному исполнению лебёдки.

## Текущий объём
- 838 исполнений
- Nidec: 831
- Sicor: 3
- Torindrive: 4
- приблизительно 559 моделей после группировки исполнений

## Ключевая модель
`execution (product_id) → model → family → manufacturer`

Одинаковая модель может иметь несколько исполнений. Каталог показывает модель одной карточкой, а подбор и дальнейшие действия работают с конкретным `product_id`.

## Основные таблицы
- `products` — JSON payload каждого исполнения
- `attributes` — динамические атрибуты
- `product_attribute_values` — значения динамических атрибутов
- `media_assets` — фото/чертежи/документы
- `inquiries` — отправленные заявки
- `inquiry_drafts` — сохранённые черновики опросника
- `settings` — системные настройки

## Важное правило
Исходные поля Excel сохраняются; нормализованные поля используются для фильтрации и UI. Неизвестное значение не должно автоматически превращаться в ноль или выдуманное значение.
