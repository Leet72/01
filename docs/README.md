# Liftorg B2B — документация проекта

GitHub `Leet72/01` является основной контрольной точкой исходного кода и проектной документации.

## Текущая стабильная версия
- Release: `v4.5.0`
- Branch: `main`
- Commit: `0902f29`
- Назначение: инженерный B2B-каталог/конфигуратор лифтовых лебёдок.

## Навигация
- `ARCHITECTURE.md` — архитектура и потоки данных.
- `DATABASE.md` — модель каталога и база данных.
- `SELECTION_LOGIC.md` — правила инженерного подбора.
- `PRODUCT_CARD_SPEC.md` — карточка товара, исполнения и сравнение.
- `SOURCE_REGISTER.md` — источники требований и приоритеты.
- `DEPLOYMENT_AND_BACKUP.md` — развёртывание и backup.
- `ROADMAP.md` — статус и следующие этапы.
- `customer/` — исходные документы и комментарии заказчика.

## Что не хранится в Git
- рабочий `storage/catalog.db`;
- `.env`, токены, пароли, SSH-ключи;
- runtime backups;
- тяжёлая медиатека/CAD/ZIP без Git LFS.
