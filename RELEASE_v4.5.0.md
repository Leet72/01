# v4.5.0 — Product Card + Comparison Redesign — 09.09.2026

По комментариям заказчика к карточке Torindrive GTW9S и последующему UX-уточнению переработаны карточка товара и сравнение.

Реализовано:
- карточка перестроена как инженерный паспорт: шапка с ключевыми параметрами, отдельные блоки «Основное», «Привод», «КВШ и канаты», «Эксплуатация», «Тормоз», «Габариты и присоединение»;
- размерность перенесена в наименование параметра;
- скорость выводится единообразно с одним знаком после запятой (например, 1,0 м/с);
- для безредукторных машин «Количество скоростей» не выводится в карточке;
- форма ручья U/V/VH получает понятную расшифровку;
- «Канаты» заменено на «Число канатов, шт. × Диаметр канатов, мм»;
- «Шаг канавок» заменён на «Расстояние между канатами, мм»;
- «Тормоз» заменён на «Напряжение тормоза, В», добавлено отдельное поле «Номинальный ток, А» при наличии данных;
- высота подъёма не выдумывается при отсутствии источника: выводится «Определяется по результатам подбора»;
- габаритные и присоединительные размеры, отсутствующие в структуре каталога, направляют пользователя к техническому чертежу;
- действия «Сравнить / Рассчитать / Опросный лист / Заказать» собраны в компактную панель;
- сравнение по умолчанию открывается в режиме «Только отличия»;
- одинаковые значения визуально приглушаются, отличающиеся — подсвечиваются;
- сверху сравнения выводится краткая строка «Главные отличия»;
- из сравнения можно сразу открыть карточку или расчёт выбранного исполнения;
- мобильная карточка получила компактную sticky-панель действий.

GTW9S: по прямому комментарию заказчика для текущего исполнения зафиксированы подвес 1:1, режим работы S5 (40%), 180 включений/час и номинальный ток тормоза 2×1,28 А. Параметры, отсутствующие в исходных данных (угол подреза, часть габаритов), самостоятельно не придумываются.
