# Liftorg B2B — Current Status v4.5.0

Статус: release candidate.

## Ключевые изменения
- переработана инженерная карточка товара;
- единый формат «Наименование параметра, размерность»;
- учтены комментарии заказчика по GTW9S;
- сравнение упрощено и по умолчанию показывает только отличия;
- карточка и сравнение адаптированы под мобильный экран;
- исходные значения не выдумываются: отсутствующие инженерные данные помечаются как требующие подбора/чертежа.

## База
Сохраняется baseline 838 исполнений. WJC-T: объёмная таблетка + MRL.

## Проверка перед production
1. Каталог открывается без JS-ошибок.
2. GTW9S показывает скорость 1,0 м/с, подвес 1:1, S5 (40%), 180 включений/час.
3. Для безредукторной GTW9S не выводится количество скоростей.
4. Сравнение 2–4 исполнений открывается в режиме «Только отличия».
5. Переключение «Все параметры» возвращает полный набор.
6. Калькулятор, опросник, заказ и persistent media не регрессируют.
